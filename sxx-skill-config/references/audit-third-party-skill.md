# 第三方技能安全审计（AI 指南）

## 目标

对“从网上下载/来源不明”的技能做安全审计，回答一个核心问题：

这个技能在运行时，是否可能对用户的电脑、账号、隐私、数据造成风险？

输出物必须是一份可读的审计报告（带证据、风险等级、建议）。

## 审计原则

- 默认不信任：除非证据充分，否则按“有风险”处理。
- 关注“能做什么”，而不是“作者是否泄露自己的密钥”。
- 先静态审计，必要时再在隔离环境做动态验证（不要在有真实隐私数据的环境直接运行）。
- 报告要能让用户做决策：用/不用/怎么用更安全。

## 静态审计清单（按顺序）

### 1) 识别“执行入口”

- 找到技能的入口脚本（通常在 `scripts/`、`main.*`、`index.*`、`SKILL.md`中引用）。
- 列出它会如何运行：命令行、浏览器自动化、调用外部程序、需要哪些依赖。

### 2) 文件系统风险

重点查：
- 删除：`rm -rf`、`rmSync/unlinkSync/rmdirSync/fs.rm({ recursive: true })`
- 覆盖写入：写入到 `~`、`/`、`Documents/Desktop`、系统配置目录
- 扫盘/批量读取：递归遍历整个用户目录、读取浏览器配置、读取密钥目录

需要在报告中回答：
- 它会写/删哪些路径？是否有保护（只在输出目录）？
- 是否存在“一不小心删错目录”的可能？

### 3) 外部命令/脚本执行风险

重点查：
- Node/Bun：`child_process`、`exec/execSync/spawn/spawnSync`
- Shell：`bash -lc`、`sh -c`、`powershell`、`osascript`
- 动态执行：`eval`、`new Function`、从字符串拼接命令

需要回答：
- 执行的命令来自哪里（硬编码/用户输入/网络下载）？
- 是否可能被注入（拼接字符串、未过滤参数）？

### 4) 网络通信与数据外传风险

重点查：
- `fetch`、`axios`、`http/https`、`WebSocket`
- 上传/埋点：`upload`、`telemetry`、`sentry`、`report`、`beacon`
- 发送到不明域名：硬编码 URL、Webhook、短链
- 如果包含本地网页/HTTP 服务：确认只监听 `127.0.0.1`（不要绑定 `0.0.0.0`），避免把本机配置/凭据暴露到局域网

需要回答：
- 它会访问哪些域名/接口？目的是什么？
- 是否可能把本地文件、Cookie、令牌、文章内容等上传到第三方？
- 是否有“静默上报”（用户不知情）？

### 5) 凭据与隐私数据访问风险

重点查：
- 读取浏览器 Cookie/Profile（Chrome/Edge/Firefox）、读取 Keychain
- 读取 `~/.ssh`、`~/.aws`、`~/.config`、`~/.npmrc`、`~/.git-credentials`
- 读取聊天记录/剪贴板/截图/相册

需要回答：
- 它试图获取哪些敏感数据？是否真的业务需要？
- 是否存在把这些数据写入日志/输出目录/网络请求的路径？

### 6) 依赖安装与供应链风险

重点查：
- `bun install` / `npm install` / `pnpm install` / `yarn add`
- `package.json` 中 `postinstall/preinstall` 脚本
- 下载二进制、从 Git 拉代码后立即执行

需要回答：
- 是否要求安装大量依赖？是否锁版本？
- 安装过程是否会执行脚本？脚本做了什么？

### 7) 持久化与系统修改风险

重点查：
- 修改 shell 配置：`~/.zshrc`、`~/.bashrc`
- 修改启动项：LaunchAgents/计划任务/注册表（Windows）
- 修改系统安全设置/代理/证书

需要回答：
- 是否会对系统做“长期驻留”或“隐蔽修改”？

## 审计报告模板（必须按此输出）

### 结论

- 是否建议使用：建议 / 谨慎使用 / 不建议使用
- 总体风险等级：低 / 中 / 高
- 使用条件（如果“谨慎使用”）：需要哪些隔离/限制/修改才能使用

### 关键发现（按严重程度排序）

每条发现至少包含：
- 风险等级：高 / 中 / 低
- 位置证据：文件路径 + 关键代码片段（简短）
- 风险说明：它可能造成什么后果
- 触发条件：什么情况下会发生
- 建议：怎么修复/怎么绕开/怎么隔离

### 不确定项与需要用户确认的问题

列出你无法从静态代码确定的点，并给出需要用户确认的信息（例如运行参数、环境、账号）。

### 建议的下一步

例如：
- 先在隔离环境跑一次（无敏感数据）
- 删除/禁用某些危险功能
- 改造成使用统一配置并去除外传行为
